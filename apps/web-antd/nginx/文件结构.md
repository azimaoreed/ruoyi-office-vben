### 3️⃣ 配置文件

#### ✅ 使用中的配置

##### 📝 ruoyi-office.conf
- **用途**: 统一的 Nginx 配置文件（唯一使用的配置）
- **适合**: 部署到服务器的配置文件
- **内容**: 
  - VitePress 文档站点配置（根路径 `/`）
  - Vben Admin 管理后台配置（子路径 `/web`）
  - 完整的性能优化（Gzip、缓存）
  - 安全配置（隐藏文件保护）
  - 健康检查接口
- **状态**: ✅ 生产使用中
- **位置**: 
  - 本地：`nginx/ruoyi-office.conf`
  - 服务器：`/data/nginx/conf/conf.d/ruoyi-office.conf`

#### ⚠️ 已弃用的配置（不要使用）

##### 📝 default.conf
- **用途**: Nginx 原始默认配置
- **状态**: ⚠️ 已弃用
- **问题**: 基础配置，缺少性能优化
- **替代**: `ruoyi-office.conf`

##### 📝 ruoyi-office-doc.conf
- **用途**: VitePress 文档独立配置
- **状态**: ⚠️ 已弃用
- **问题**: 独立配置，会与其他配置冲突
- **替代**: `ruoyi-office.conf`

##### 📝 web-antd.conf
- **用途**: Vben Admin 独立配置
- **状态**: ❌ 已弃用（有语法错误）
- **问题**: 
  - **语法错误**: `location` 指令直接放在文件顶层，必须在 `server` 块内
  - **错误信息**: `nginx: [emerg] "location" directive is not allowed here`
- **替代**: `ruoyi-office.conf`

### 4️⃣ 工具脚本

#### 🔧 deploy-nginx-config.sh
- **用途**: 自动化部署脚本
- **功能**:
  1. ✅ 自动备份现有配置
  2. ✅ 上传新配置文件
  3. ✅ 删除旧配置文件
  4. ✅ 验证配置语法
  5. ✅ 重新加载 Nginx
  6. ✅ 验证部署结果
  7. ✅ 失败自动回滚
- **使用**:
  ```bash
  chmod +x deploy-nginx-config.sh
  ./deploy-nginx-config.sh
  ```
- **优先级**: ⭐⭐⭐⭐⭐

## 🗂️ 服务器端文件组织

### 部署前（旧配置）

```
/data/nginx/conf/conf.d/
├── default.conf                # Nginx 默认配置
├── ruoyi-office-doc.conf       # VitePress 配置
└── web-antd.conf               # Vben 配置（语法错误）
```

**问题**:
- ❌ `web-antd.conf` 语法错误
- ⚠️ 配置分散，难以管理
- ⚠️ 可能存在端口冲突

### 部署后（新配置）

```
/data/nginx/conf/conf.d/
├── ruoyi-office.conf           # ✅ 统一配置（使用中）
└── backup-20260121-153000/     # 备份目录
    ├── default.conf            # 旧配置备份
    ├── ruoyi-office-doc.conf   # 旧配置备份
    └── web-antd.conf           # 旧配置备份
```

**优势**:
- ✅ 只有一个配置文件
- ✅ 旧配置已备份
- ✅ 配置语法正确
- ✅ 易于管理和维护
