# Nginx 统一配置快速部署指南

## 🚀 一键部署（推荐）

```bash

cd w:/ruoyi-office/ruoyi-office-vben/apps/web-antd/nginx
```

## 🔙 回滚配置

如果部署后出现问题，可以快速回滚：

```bash
# 1. 找到备份目录
ssh root@182.92.106.252 'ls -lt /data/nginx/conf/conf.d/ | grep backup'

# 2. 回滚到指定备份（替换时间戳）
ssh root@182.92.106.252 << 'EOF'
BACKUP_DIR="/data/nginx/conf/conf.d/backup-20260121-153000"
rm -f /data/nginx/conf/conf.d/ruoyi-office.conf
cp ${BACKUP_DIR}/*.conf /data/nginx/conf/conf.d/
docker exec nginx nginx -t && docker exec nginx nginx -s reload
echo "✓ 回滚完成"
EOF
```

## 🛠️ 故障排查

### 问题1: 配置语法错误

**症状**: `nginx -t` 失败

**解决**:

```bash
# 查看错误详情
ssh root@182.92.106.252 'docker exec nginx nginx -t'

# 检查配置文件内容
ssh root@182.92.106.252 'cat /data/nginx/conf/conf.d/ruoyi-office.conf'
```

### 问题2: 页面 404

**症状**: 访问 http://182.92.106.252/web 返回 404

**解决**:

```bash
# 1. 检查文件是否存在
ssh root@182.92.106.252 'ls -lh /usr/share/nginx/html/web/'

# 2. 检查文件权限
ssh root@182.92.106.252 'ls -la /usr/share/nginx/html/web/'

# 3. 检查 Nginx 错误日志
ssh root@182.92.106.252 'docker exec nginx tail -100 /var/log/nginx/ruoyi-office-error.log'
```

### 问题3: 静态资源 404

**症状**: 页面打开但 CSS/JS 加载失败

**可能原因**:

- Vite 构建时的 `base` 配置不正确
- Nginx `alias` 配置错误

**解决**:

```bash
# 1. 检查 vite.config.mts 中的 base 配置
# 应该是: base: process.env.NODE_ENV === 'production' ? '/web/' : '/'

# 2. 检查 Nginx location /web 配置
ssh root@182.92.106.252 'grep -A 10 "location /web" /data/nginx/conf/conf.d/ruoyi-office.conf'

# 3. 查看访问日志，确认请求路径
ssh root@182.92.106.252 'docker exec nginx tail -100 /var/log/nginx/ruoyi-office-access.log | grep 404'
```

### 问题4: Gzip 压缩未生效

**验证方法**:

```bash
# 检查响应头
curl -I -H "Accept-Encoding: gzip" http://182.92.106.252/web

# 应该包含: Content-Encoding: gzip
```

**解决**: 检查 Nginx 配置中的 gzip 指令
